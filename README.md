# VS Code Remote SSH Lab

This repository is used for learning and testing GitHub fundamentals while developing inside an Ubuntu virtual machine through a remote SSH connection from VS Code.

## Purpose

This project provides a place to:

- Test VS Code Remote - SSH with an Ubuntu VM
- Create and experiment with projects inside the VM
- Practice Git and GitHub workflows
- Learn how to clone, fetch, pull, commit, push, and branch
- Experiment safely without affecting production projects

## Development Environment

- **Host:** Windows PC
- **Virtualization:** Hyper-V
- **Guest operating system:** Ubuntu
- **Editor:** Visual Studio Code
- **Connection:** Remote - SSH
- **Repository hosting:** GitHub

Although VS Code runs on the Windows host, the code, terminal commands, Git operations, and projects are intended to run inside the Ubuntu VM.

## GitHub Fundamentals

This repository is also used to practice:

- Creating and organizing repositories
- Writing meaningful commit messages
- Working with branches
- Using `git fetch`, `git pull`, and `git push`
- Reviewing project history
- Using issues and documentation
- Managing projects safely with `.gitignore`

## Status

This is an experimental learning repository. Its contents may change as new projects, tests, and GitHub exercises are added.
